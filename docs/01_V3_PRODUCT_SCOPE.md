# Product Scope

YouTube AI Studio V3 is a schema-driven authoring import and local production application.

The user creates Topic Ideas, a combined Script and Script Analysis response, and a full-Script Scene Breakdown response with external ChatGPT. The tool builds authoritative copyable prompts, validates imported JSON, publishes canonical immutable artifacts, and runs Voice from Script, Style Bible, Visual References, full-Script Scene Breakdown after approved Voice, an internal hidden Prompt Bundle, Scene Assets, Assembly, subtitles, and FFmpeg Render. Scene Breakdown approval automatically compiles one Prompt Bundle item for every beat, publishes BeatTimingMap, and every beat is rendered through the media provider.

Internal LLM execution, internal web research, multi-user collaboration, cloud deployment, and compatibility with discarded development artifacts are outside scope.
